# Тестове: карта станцій

Цей пакет містить frontend-задачу, стартовий Vue 3-проєкт і локальний API із синтетичними даними. API працює всередині dev-сервера `Vite` і запускається разом із frontend.

## Вміст

- `candidate-task.md` — завдання.
- `frontend/` — Vue 3-проєкт на `Vite` і схематична фонова карта.
- `api/` — контракт API у форматі OpenAPI та короткі інструкції.
- `frontend/api-middleware.js` — локальний тестовий API, який `Vite` запускає разом із frontend.

API надає 10 000 синтетичних станцій та по 36 вимірювань для кожної, з максимум 100 записами на сторінку. Ендпоінти та схеми запитів і відповідей описані у Swagger.

## Потрібне середовище

- Node.js `20.19` або новіший `20.x`, або `22.12` чи новіший, і npm.
- Локальний API не потребує окремого Python-середовища чи процесу.

## Запуск

Із кореневої директорії пакета встановіть залежності та запустіть `Vite`:

```powershell
cd frontend
npm ci
npm run dev
```

Відкрийте адресу, яку надрукує `Vite` — типово <http://127.0.0.1:5173>. Swagger UI доступний за адресою <http://127.0.0.1:5173/docs/>. Запити до `/api` обробляються тим самим локальним сервером.

## Рішення, припущення та обмеження

**Стек.** Vue 3 (`<script setup>`) + Leaflet з тайлами OpenStreetMap (потрібен інтернет). Графік динаміки — власний SVG без додаткових бібліотек. Стан станцій і вимірювань винесено в композабл `src/composables/useStations.js`.

**Ключові рішення.**
- Станції завантажуються за `bbox` поточної області карти (із затримкою після руху); пошук іде по всій базі через `search`, після чого карта підганяється під знайдені станції.
- API віддає максимум 100 записів, а станцій 10 000, тому інтерфейс завжди показує «N із M» і має кнопку «Показати ще» (`cursor`) та підказку наблизити карту.
- Відповіді `503` обробляються автоматично: до 2 повторів з наростаючою паузою, потім повідомлення з кнопкою «Спробувати ще раз». Застарілі запити скасовуються (`AbortController` + лічильник запитів), тому швидкий рух карти чи набір тексту не перезаписують свіжіші дані.
- На екранах ≤1260px картка станції висувається з правого боку і відкривається автоматично при виборі станції; список станцій на ≤860px закривається після вибору.
- Динаміку рівня (графік і список) будуємо за 36 вимірами станції; діапазони «7 дн. / 15 дн. / Усі» рахуються від часу останнього виміру, а не від поточної дати, бо дані синтетичні (січень 2026).

**Що перевірено.** Роботу API (bbox, пошук, пагінація, історія вимірів) — окремим скриптом проти локального middleware; форматування дат і чисел. <!-- ДОПОВНІТЬ власними перевірками: інтерфейс у браузері на 1440/1024/768/390px, поведінка при TEST_API_ERROR_RATE=0.5, `npm run build`, `npm run format:check`. -->

**Відомі обмеження.**
- Немає кластеризації маркерів: на великому масштабі видно лише завантажену сторінку станцій (до 100, далі «Показати ще»).
- Пошук не враховує межі карти (API не поєднує `search` з областю осмислено), а результати показуються в порядку ID.
- Графік простий: без підказок при наведенні та осей часу, лише мінімум/максимум і крайні дати.
- Автотестів на інтерфейс немає; наявні тести покривають лише тестовий API.
